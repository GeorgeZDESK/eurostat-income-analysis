# Eurostat Income Analysis

A Python project exploring equivalised disposable income across Europe, with a focus on Greece and the Balkans. The analysis will compare income by age and sex, track changes over time, and examine differences between mean and median income.

**Work in progress.**

## Data

Source: [Eurostat, Mean and median income by age and sex (`ilc_di03`)](https://ec.europa.eu/eurostat/databrowser/view/ilc_di03/default/table?lang=en).

The original CSV is kept unchanged in `data/raw/`.
