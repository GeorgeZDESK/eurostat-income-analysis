# Reproducing the analysis

## Setup

The recorded environment uses Python 3.13.17 on Windows. Use VS Code with the Python and Jupyter extensions and an activated Python environment matching that version.

From the repository root, install the recorded packages and check their dependencies:

```bash
python -m pip install -r requirements-notebook.txt
python -m pip check
```

`requirements.txt` records the analysis packages. `requirements-notebook.txt` includes them and adds the IPython kernel packages used in VS Code.

Select that environment as the kernel for each notebook. For local kernels, set `jupyter.notebookFileRoot` to `${fileDirname}`, the [extension's default](https://github.com/microsoft/vscode-jupyter/blob/main/package.json). All three notebooks must run with `notebooks/` as their working directory. This supports both the existing `../data/` paths and the local `income_utils` import.

## Execution order and files

Use **Restart Kernel**, then **Run All**, for each notebook in this order:

| Notebook | Purpose |
| --- | --- |
| `notebooks/01_eda.ipynb` | Audit the raw exports and generate processed CSVs. |
| `notebooks/02_income_analysis.ipynb` | Analyse Greece: income, ages, inflation, housing and urbanisation. |
| `notebooks/03_europe_income_analysis.ipynb` | Compare countries, coverage, age groups, housing and real income changes. |

`02` and `03` independently read the files produced by `01`; they do not share kernel variables. The shared HICP merge function is in `notebooks/income_utils.py`.

| Location | Contents |
| --- | --- |
| `data/raw/` | The four original Eurostat CSV exports used by this project. |
| `data/processed/` | Nine CSVs generated by `01`, including the two income tables. |
| `reports/figures/` | PNG charts generated by `02` and `03`. |

Use the committed raw snapshots when reproducing the baseline. Refreshing the exports is a separate change.

## Data and transformations

Source links checked on 2026-11-03. Original CSV download dates have not been verified.

| Eurostat dataset | Use in this project |
| --- | --- |
| [ilc_di03](https://ec.europa.eu/eurostat/databrowser/view/ilc_di03/default/table?lang=en) | Mean and median income by age and sex; current analysis selects total sex (`T`). |
| [prc_hicp_ainr](https://ec.europa.eu/eurostat/databrowser/view/prc_hicp_ainr/default/table?lang=en) | Annual average, all-items HICP for inflation adjustment. |
| [ilc_lvho07a](https://ec.europa.eu/eurostat/databrowser/view/ilc_lvho07a/default/table?lang=en) | Housing cost overburden by age, sex and poverty status. |
| [ilc_di17](https://ec.europa.eu/eurostat/databrowser/view/ilc_di17/default/table?lang=en) | Income by degree of urbanisation. |

- [Equivalised disposable income](https://ec.europa.eu/eurostat/statistics-explained/index.php?title=Glossary:Equivalised_disposable_income) adjusts disposable household income for household size and composition. The CSV rows are published group statistics, not individual wages.
- Income selections use survey years 2003–2025. Age comparisons keep the published groups 0–17, 18–24, 25–49, 50–64 and 65+ separate; `TOTAL` is a separate population selection. Mean, median, EUR, NAC and PPS remain distinct.
- Greek survey years 2003–2025 map to income years 2002–2024. The Greek real-income charts use 2024 prices. The European real-change comparison covers income years 2019–2023, using NAC within each country. In this snapshot, Croatian NAC amounts through survey year 2022 are divided by [7.53450 kuna per euro](https://www.ecb.europa.eu/euro/changeover/croatia/html/index.en.html). HICP is matched to the income year.
- Values, missing values and complete flag strings are retained within the selected records. An absent country–year is not a zero. Historical reference periods, coverage and breaks require country/year context: see [EU-SILC metadata](https://ec.europa.eu/eurostat/cache/metadata/en/ilc_sieusilc.htm) and [HICP metadata](https://ec.europa.eu/eurostat/cache/metadata/en/prc_hicp_esms.htm). These descriptive comparisons do not establish causality.

Filtering, labels, currency adjustments, calculations and charts are the author's work. Eurostat is not responsible for these transformations or interpretations. See its [reuse policy](https://ec.europa.eu/eurostat/help/copyright-notice).

The income checks compare all retained source columns exactly against the selected raw records, including missingness and flags. The HICP helper validates many-to-one joins, rejects missing join keys and reports unmatched keys while keeping income rows.

The numerical check also verifies the Greek endpoint survey years, 2020 and 2024. Its percentage tolerance is `1e-6` percentage points because the reference percentage is rounded to six decimal places.
